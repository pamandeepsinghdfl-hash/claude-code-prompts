# Stock footage

Optional CC0 / royalty-free vertical clips for the public-domain fallback path.

If this folder is empty AND `PIXABAY_API_KEY` is set in `.env`, the factory
will fetch vertical CC0 clips from Pixabay at runtime. Otherwise, seed this
folder with 9:16 MP4s (or any MP4 — the editor will crop to 9:16).

Recommended sources (all free, no attribution required):
  • https://pixabay.com/videos/
  • https://www.pexels.com/videos/
  • https://coverr.co/
  • https://mixkit.co/
