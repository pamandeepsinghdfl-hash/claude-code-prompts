# Background music

Drop royalty-free MP3 / WAV / OGG / M4A files here. The factory picks
one at random per Short and mixes it under the original audio at the
volume defined in `config.yaml -> video.music_volume` (default 10%).

Recommended sources:
  • YouTube Audio Library (https://www.youtube.com/audiolibrary)
  • Pixabay Music (https://pixabay.com/music/)
  • Free Music Archive (https://freemusicarchive.org/)
  • Incompetech (https://incompetech.com/)

ONLY use tracks marked CC0 / royalty-free / "no attribution required",
OR keep attribution in the Short's description if the license demands it.
